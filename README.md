Welcome to the official repository for the personal portfolio of **Kesha K. Kaneria**, AI Product Manager and Product Strategist specializing in shipping LLM applications, RAG pipelines, agentic workflows, and AI search platforms at scale.

This portfolio is a sleek, modern, and high-performance React application crafted to showcase 12+ enterprise AI products, $15M+ business impact, hallucination reduction metrics, and a deep strategic approach to 0→1 product leadership.

---

## 🚀 Tech Stack & Design System

- **Framework**: [React](https://react.dev/) + [Vite](https://vite.dev/) (TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **State & Data**: React Query (TanStack Query)
- **Aesthetics**: Light/warm minimalist design (`--background: 40 30% 97%`) featuring premium transitions, custom scroll-reveals, and abstract geometric SVG illustrations.

## 🛠️ Local Development

To run the project locally on your machine:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start the Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser to the local URL (usually `http://localhost:8080`).

3. **Run Production Build**:
   ```bash
   npm run build
   ```
